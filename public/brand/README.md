# RouteHQ brand assets

RouteHQ uses a deep azure/navy base with vibrant orange accents.

- Application mark: `public/app-icon.svg`
- Browser favicon: `public/favicon.svg`
- Product name and browser title: `index.html`

The current mark is a simple interim monogram. Replace it with approved final brand artwork when the identity system is signed off.

Do not put customer documents, passports, receipts, or other private files in this folder. Anything under `public/` is included in the public website build and can be accessed by anyone who knows its URL.
