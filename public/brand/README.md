# RouteHQ brand assets

This folder is the designated location for approved RouteHQ logo files.

## Uploading the logo

Add the final logo here using one of these filenames:

- `routehq-logo.svg` (preferred, vector with transparent background)
- `routehq-logo.png` (transparent PNG, high resolution)

Keep a horizontal/primary logo and, if needed, a separate compact mark. Do not overwrite the interim application icon unless the replacement is also approved for favicon/app-icon use.

The current application icon and favicon are:

- `public/app-icon.svg`
- `public/favicon.svg`

The interface uses a graphite/obsidian foundation with restrained orange and blue accents. The logo should remain legible on both dark and light backgrounds. If only one version is supplied, use a transparent version with sufficient contrast.

**Public-folder warning:** everything inside `public/` is shipped with the public website build and can be accessed by anyone who knows its URL. Do not put customer documents, passports, receipts, credentials, or private brand drafts here.
